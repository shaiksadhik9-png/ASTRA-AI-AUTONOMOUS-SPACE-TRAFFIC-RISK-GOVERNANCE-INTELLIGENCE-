# ASTRA-AI: Autonomous Space Traffic Risk & Governance Intelligence

ASTRA-AI is an AI-powered Space Situational Awareness and Decision Support System designed to monitor satellites, space debris, orbital traffic, weather conditions, disaster events, and governance activities in real time.

The platform combines Artificial Intelligence, Generative AI (Google Gemini), data visualization, and geospatial analytics to provide intelligent insights for space traffic management, disaster monitoring, and governance decision-making.

## Features

- 🌍 3D Earth Visualization
- 🛰️ Satellite & Orbital Traffic Monitoring
- ☄️ Space Debris Risk Analysis
- 🌦️ Weather Intelligence Dashboard
- 🌪️ Disaster Response Center
- 📊 Geo Analytics Dashboard
- 🤖 AI Decision Support using Google Gemini
- 📋 Governance Audit Logs
- 📈 Interactive Charts & Visualizations
- 🔒 Secure AI-powered Monitoring System

## Technology Stack

- React 19
- TypeScript

- D3.js

## Installation

### Prerequisites

- Node.js 20+
- npm

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env` file in the project root and add:

```env
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

### Run the Project

```bash
npm run dev
```

The application will be available at:

```
http://localhost:3000
```
